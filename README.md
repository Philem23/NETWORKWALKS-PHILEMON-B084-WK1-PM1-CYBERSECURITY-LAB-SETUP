## 1. Project Overview

This project involved setting up a virtual cybersecurity testing environment using Oracle VirtualBox and Kali Linux.

The objective was to establish a controlled laboratory environment for future cybersecurity and ethical hacking practical exercises.

## 2. Lab Requirements

The project involved the following configurations:

- Oracle VirtualBox as the virtualization platform.
- Kali Linux as the primary cybersecurity testing machine.
- VirtualBox NAT Network configured with the `10.0.0.0/24` subnet.
- Static IP configuration for Kali Linux: `10.0.0.2/24`.
- Internet connectivity for the Kali virtual machine.
- Shared Clipboard and Drag and Drop functionality enabled.
- Host shared folder configured at `/downloads`.
- Virtual machine snapshot created after configuration.

## 3. Implementation

### 3.1 VirtualBox Installation

Installed Oracle VirtualBox and prepared the virtualization environment for the Kali Linux virtual machine.

### 3.2 NAT Network Configuration

Created a custom NAT Network in VirtualBox using the specified `10.0.0.0/24` subnet.

### 3.3 Kali Linux Installation

Downloaded and imported the Kali Linux virtual machine into VirtualBox and configured its network adapter.

### 3.4 IP Configuration

Configured the Kali Linux network interface with the assigned static IPv4 address.

### 3.5 VM Integration

Configured clipboard sharing, drag-and-drop functionality and host shared-folder integration.

### 3.6 Snapshot Configuration

Created a virtual machine snapshot to preserve the configured lab environment for future practical exercises.
